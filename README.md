# مدیریت سفر شمال — PWA UI
نسخه اولیه رابط کاربری موبایل‌محور و RTL. این نسخه نمایشی است و هنوز به Supabase متصل نشده است.

## اجرا
فایل‌ها را روی GitHub Pages یا هر static host قرار دهید. برای Service Worker بهتر است از HTTPS استفاده شود.

## v11 — ثبت واقعی هزینه
1. فایل `database/expense-rpc.sql` را در Supabase SQL Editor اجرا کنید.
2. همه فایل‌های ZIP را جایگزین فایل‌های repository در GitHub کنید.
3. بعد از انتشار، با Ctrl+F5 برنامه را باز کنید.
4. وارد حساب شوید و از «هزینه‌ها» گزینه «ثبت هزینه جدید» را تست کنید.

هزینه‌ها ابتدا با وضعیت `pending` ذخیره می‌شوند؛ همه اعضای سفر آن را می‌بینند و فقط مدیر می‌تواند تأیید یا رد کند. سهم اعضا از ضریب ثابت `share_weight` در `trip_members` محاسبه می‌شود.
