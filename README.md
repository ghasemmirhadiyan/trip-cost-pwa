# مدیریت سفر خانوادگی — نسخه 15.0

## تغییرات
- لینک دعوت برای ثبت‌نام اعضا
- ساخت حساب توسط فرد دعوت‌شده و ارسال درخواست عضویت برای مدیر
- عضو تا تأیید مدیر فعال نمی‌شود
- ضریب پیش‌فرض عضویت: 1
- مدیر هنگام تأیید می‌تواند ضریب را تغییر دهد
- تعهد صندوق به‌صورت خودکار = ضریب × مبلغ هر سهم

## راه‌اندازی
1. برای تغییرات مالی نسخه 14.2، اجرای SQL جدید لازم نیست. همان دیتابیس فعلی کافی است.
2. محتوای پوشه پروژه را روی GitHub Pages جایگزین کنید.
3. یک بار Ctrl+F5 بزنید.

این بسته عمداً فقط فایل‌های لازم نسخه نهایی را دارد و فایل‌های نسخه‌های قبلی داخل آن نیستند.

## نسخه 15.0
- نصب PWA روی Android با دکمه نصب و manifest استاندارد.
- آیکن‌های 192 و 512 پیکسل برای نصب Android.
- نمایش پیام شخصی بدهی/طلب به صندوق و سایر اعضا بعد از ورود.
- محاسبه تسویه هوشمند شخص‌به‌شخص بر اساس هزینه‌های تأییدشده.


## منطق مالی نسخه 14.2
- در طول سفر پیام مالی شخصی فقط بدهی/طلب کاربر نسبت به صندوق را نمایش می‌دهد.
- تسویه بین اعضا فقط در بخش «تسویه نهایی» و بر اساس هزینه‌های شخصیِ تأییدشده محاسبه می‌شود.
- در پایان سفر، مانده صندوق نیز مشخص می‌کند چه مبلغی باید به اعضا برگردد یا چه مقدار کسری باید از اعضای بدهکار وصول شود.
