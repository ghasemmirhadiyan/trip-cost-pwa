# مدیریت سفر گروهی — نسخه 15.5

## تغییرات نسخه 15.5
- ویرایش تراکنش‌های صندوق توسط مدیر سفر؛ شامل واریزکننده، مبلغ، تاریخ، روش پرداخت و توضیحات. وضعیت تراکنش حفظ می‌شود.
- پنل مدیریت برای تنظیم «پیام اعضا هنگام ورود»؛ پیام فعال برای اعضای عادی پس از ورود به‌صورت پاپ‌آپ نمایش داده می‌شود.
- پیام سازنده/شروع برنامه دوباره در ابتدای باز شدن برنامه نمایش داده می‌شود.
- چک‌لیست از داشبورد به‌صورت یک آیکن در «دسترسی سریع» قرار گرفت و فهرست کامل فقط در صفحه مستقل چک‌لیست نمایش داده می‌شود.
- شماره نسخه 15.5 و Cache نسخه جدید به‌روزرسانی شد.

## مهاجرت Supabase
فایل زیر را در SQL Editor پروژه Supabase اجرا کنید:
`database/migration-v15.5-announcements-contribution-edit.sql`

پس از اجرای migration، فایل‌های این بسته را روی GitHub Pages جایگزین کنید.


## تغییرات نسخه 15.5
- مدیر سفر می‌تواند تراکنش‌های صندوق را حذف کند.
- حذف تراکنش از طریق RPC امن و فقط برای مدیر همان سفر انجام می‌شود.
- اگر تراکنش تأییدشده حذف شود، موجودی و محاسبات صندوق به‌صورت خودکار بر اساس داده‌های باقی‌مانده محاسبه می‌شوند.
- اگر کاربر ۳۰ دقیقه هیچ فعالیتی نداشته باشد، نشست محلی او خاتمه یافته و صفحه ورود دوباره نمایش داده می‌شود.
- اگر برنامه پس از مدت طولانی عدم فعالیت دوباره باز شود، آخرین زمان فعالیت بررسی می‌شود و در صورت عبور از ۳۰ دقیقه، ورود مجدد الزامی خواهد بود.
- خروج خودکار فقط همان نشست دستگاه/مرورگر را خارج می‌کند (`scope: local`).
