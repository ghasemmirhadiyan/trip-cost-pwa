# نسخه 11.8 — حالت تک‌سفر

- انتخاب بین سفرها حذف شده است.
- برنامه فقط یک سفر فعال را برای هر حساب در نظر می‌گیرد.
- گزینه ایجاد سفر جدید از پنل مدیریت حذف شده است.
- ادمین می‌تواند از بخش اعضا حساب کاربری کامل بسازد و عضو را مستقیم به سفر اضافه کند.
- محاسبات مالی همچنان از Supabase و Viewهای مالی موجود انجام می‌شوند.
- درخواست‌های عضویت از رابط کاربری حذف شده‌اند تا خطای membership_requests ایجاد نشود.

## پاک‌سازی دیتابیس
فایل `database/reset-to-single-trip.sql` را در SQL Editor اجرا کنید. این فایل حساب‌های Auth و پروفایل‌ها را حذف نمی‌کند؛ یک سفر دارای ادمین را نگه می‌دارد و داده‌های سفر را از صفر می‌کند.
